A* Algorithm

Start by selecting the source node (node 0), then find the shortest path to the goal using f(n) = g(n) + h(n).

  • Pick the unvisited node with the smallest f(n) = g(n) + h(n).
  • Relax edges only to neighbors that improve g(n).

A*:
1. Goal: Find shortest path from source node "s" to goal node "g"
2. Initialize g(s)=0, g(other)=∞
3. f(n) = g(n) + h(n)
4. Repeat until goal is reached:
   + select unvisited node with smallest f(n)
   + for each neighbor v:
     - compute new g = g(current) + weight
     - if new g < old g:
         update g(v)
         update f(v)

        Explanation:  

The treasure chests are nodes, and the lines between them are weighted edges. 
Your goal is to find the shortest path from the starting node to a specific goal node. 

A* algorithm improves on Dijkstra’s approach by using a heuristic — an estimate of how far each node is from the goal. 

For each node, A* computes:
g(n) = the distance from the start node to n  
h(n) = the estimated distance from n to the goal  
f(n) = g(n) + h(n)

At every step, A* selects the unvisited node with the smallest f(n) value, guiding the search intelligently toward the goal.
