HeapSort(Array as Arr):
1. Do BuildMaxHeap 
2. Repeat until Arr is sorted:
3.   Swap root with the last element
4.   Reduce heap size
5.   Heapify to restore heap property

BuildMaxHeap():
1. Iterate from last non-leaf node to root:
2.   Heapify the subtree

Heapify():
1. For the subtree at specified index:
2.   Ensure root  larger than its children
3.   Swap with the largest child if necessary
4.   Recursively Heapify the affected subtree

Explanation:
The treasure chests represent nodes and the lines between the treasure chests represent edges. Your goal here is to connect open all the chests, In other words, find a minimum spanning tree ("MST") for this graph. To get a MST, you have to find a subset of the edges connecting all nodes without forming cycles. The total weight must be minimum.
